# .NET Core API 架構設計練習專案

## 專案說明
本專案為後端架構設計練習，主要目的是驗證與實作常見的系統分層設計與程式結構，並非完整業務系統。

專案內容以架構設計為主，部分功能為簡化實作，用於展示整體設計方式與開發思路。

---

## 架構設計
採用分層架構：

- Controller：負責 API 入口與請求處理  
- Service：處理業務邏輯  
- Repository：負責資料存取  

透過 Dependency Injection 降低模組間耦合，使系統更易於測試與擴展。

---

## 技術重點

- .NET Core Web API  
- Dependency Injection  
- 分層架構設計  

---

## 單元測試

針對核心邏輯進行單元測試，以驗證架構設計的可測試性。

---

## 設計重點

本專案重點在於：

- 分層責任劃分  
- 模組解耦  
- 架構可維護性  
- 測試友善設計  

---

## 專案目的

此專案為個人練習與驗證架構設計思維之用，著重於設計方式與系統結構，而非功能完整性。
